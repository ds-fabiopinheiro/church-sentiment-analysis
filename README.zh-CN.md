# Church Sentiment Analysis — 会众反应面板

> 面向讲道者的汇总、匿名反馈：在信息的每个部分，会场里发生了什么。

**其他语言：** [English](README.md) · [Português](README.pt-BR.md) · [हिन्दी](README.hi.md) · [বাংলা](README.bn.md) · [العربية](README.ar.md) · 中文 · [日本語](README.ja.md)

## 为什么
在 Pew Research 2016 年的调查中，83% 曾寻找新教会的人表示讲道质量影响了他们的选择——这是被提及最多的因素。然而，大多数讲道者在门口听到的只是"讲得好"。本项目为讲道者提供一个客观、匿名、汇总的视图：会众逐分钟如何反应，并与信息的文字记录关联，以便更好地准备下一篇信息。

## 它做什么
- 读取一场聚会的录像（视频文件）。
- 在会众镜头中检测人脸，并按每 30 秒的时间窗仅计算汇总值：可测量人脸数、面向讲台的比例、微笑的比例、表情活跃度。
- 转写讲台音频，并把聚会分成若干时段（敬拜、祷告、通知、讲道、呼召）。
- 找出持续的上升与下降，写出 3 到 8 条洞察，每条包含分钟、时段、引用的段落和所用的信号。

## 它绝不做的事（由代码与 CI 强制执行）
1. 绝不存储任何帧、人脸裁剪或视频副本。
2. 绝不识别任何人：没有人脸识别、没有 embeddings、没有跨帧跟踪、不与会员记录关联。
3. 绝不报告可测量人脸少于 10 的时间窗；没有按座位、小区域或个人的任何指标。
4. 绝不说人们"感受"到了什么；措辞仅限于观察到的反应。
5. 绝不给讲道者排名，也不评价会友。

## 如何运行
同一个 Docker 镜像随处运行：
- 概念验证：在 Hugging Face Jobs 上使用最便宜的 GPU（T4 small，约每小时 0.40 美元；每场聚会约 0.30–1.10 美元）。见 `docs/hf-jobs.md`。
- 生产：教会内部的本地 NVIDIA 服务器，100% 本地部署。见 `docs/onprem.md`。

快速开始（本地、模拟引擎、无需 GPU）：
```
uv run python processar_culto.py --video service.mp4 --culto 2026-09-06-19h --provider mock --out out/
```

## 状态与路线图
- 阶段 0（当前）：使用允许下载的公开讲道视频进行概念验证；以六项可测量标准作为关口（`docs/poc-gate.md`）。
- 阶段 1：与一间教会试点（4 场聚会），在隐私影响评估并告知会众之后。
- 之后：给导播间的实时面板，以及给讲道者的低调提示。

## 给其他国家的教会
法律要求各不相同（GDPR、LGPD 及其他）。"它绝不做的事"中的规则是最低要求；处理自己的录像前请核对当地法律。欢迎贡献翻译、验证数据集和当地法律说明。
