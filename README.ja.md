# Church Sentiment Analysis — 会衆リアクション・パネル

> 説教者への集計・匿名フィードバック：メッセージの各部分で会場に何が起きたか。

**他の言語で読む：** [English](README.md) · [Português](README.pt-BR.md) · [हिन्दी](README.hi.md) · [বাংলা](README.bn.md) · [العربية](README.ar.md) · [中文](README.zh-CN.md) · 日本語

## なぜ
Pew Research の 2016 年の調査では、新しい教会を探した人の 83% が、説教の質が選択に影響したと答えました。最も多く挙げられた要因です。それでも、ほとんどの説教者が出口で聞くのは「良い説教でした」だけです。このプロジェクトは、会衆が分単位でどう反応したかを、メッセージの文字起こしと結びつけ、客観的・匿名・集計の形で説教者に示し、次のメッセージをよりよく準備できるようにします。

## 何をするか
- 録画された礼拝（動画ファイル）を読み込みます。
- 会衆が映るショットで顔を検出し、30 秒ごとの区間について集計値だけを測ります：測定可能な顔の数、壇上を向いている割合、笑顔の割合、表情の活発さ。
- 講壇の音声を文字起こしし、礼拝を場面（賛美、祈り、報告、説教、招き）に分けます。
- 持続的な上昇と下降を見つけ、3〜8 件の所見を書きます。各所見には分、場面、引用箇所、用いた信号が含まれます。

## 決してしないこと（コードと CI で強制）
1. フレーム、顔の切り抜き、動画のコピーを決して保存しません。
2. 誰も特定しません：顔認識なし、埋め込み（embeddings）なし、フレーム間の追跡なし、会員名簿との照合なし。
3. 測定可能な顔が 10 未満の区間は決して報告しません。座席・小区画・個人ごとの数値はありません。
4. 人々が何を「感じた」かは決して言いません。表現は観察された反応に限定します。
5. 説教者の順位付けや会員の評価はしません。

## 動かし方
同じ Docker イメージがどこでも動きます：
- 概念実証：Hugging Face Jobs の最も安い GPU（T4 small、1 時間あたり約 0.40 米ドル、礼拝 1 回あたり約 0.30〜1.10 米ドル）。`docs/hf-jobs.md` を参照。
- 本番：教会内のローカル NVIDIA サーバーで 100% オンプレミス。`docs/onprem.md` を参照。

クイックスタート（ローカル、モックエンジン、GPU 不要）：
```
uv run python processar_culto.py --video service.mp4 --culto 2026-09-06-19h --provider mock --out out/
```

## 状況とロードマップ
- フェーズ 0（現在）：ダウンロードが許可された公開の説教動画で概念実証。6 つの測定可能な基準によるゲート（`docs/poc-gate.md`）。
- フェーズ 1：プライバシー影響評価と会衆への告知の後、1 教会で試験運用（礼拝 4 回）。
- その後：配信ブース向けのライブパネルと、説教者への控えめな合図。

## 他国の教会へ
法的要件は国によって異なります（GDPR、LGPD など）。「決してしないこと」の規則は最低限のものです。自分の録画を処理する前に現地の法律を確認してください。翻訳、検証用データセット、現地法に関するメモの貢献を歓迎します。
